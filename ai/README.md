# 🤖 بخش هوش مصنوعی — تولید گفتار فارسی با صدای خودت

متن فارسی می‌دهی، با **صدای خودت** خوانده می‌شود. کلون صدا از یک نمونهٔ
**۵ ثانیه‌ای** انجام می‌شود.

> ⚡ **همه‌چیز روی GitHub Actions اجرا می‌شود.** روی سیستم شما هیچ‌چیز
> دانلود یا نصب نمی‌شود. حتی کامپیوترتان لازم نیست روشن باشد.

## شروع سریع

### ۱) نمونهٔ صدایت را بگذار (فقط یک‌بار)

برو به:

```
https://github.com/rahimifaeze64-art/kosar_sites/upload/main/ai/voices
```

یک فایل **wav** یا **mp3** با **حداکثر ۵ ثانیه** بگذار و اسمش را
`my_voice.wav` بگذار. بیشتر بدانید: [`voices/README.md`](voices/README.md)

### ۲) ورکفلو را اجرا کن

```
https://github.com/rahimifaeze64-art/kosar_sites/actions/workflows/ai-tts.yml
```

→ **Run workflow** → متن فارسی را در کادر بچسبان → **Run**

### ۳) صدا را بشنو

بعد از ~۳ تا ۱۵ دقیقه:

- در صفحهٔ **هوش مصنوعی** سایت: `https://alkawthar.info/ai.html`
- یا در همان صفحهٔ Actions، بخش **Artifacts**

## مسیر فنی

```
متن فارسی
   ↓ normalize_fa.normalize_for_model()   اعداد به حرف، یکسان‌سازی حروف
   ↓ Homo-GE2PE (T5)                       تبدیل به فونِم لاتین
   ↓ pocket-tts-farsi-v2                   تولید صدا با نمونهٔ شما
   ↓
فایل WAV
```

### ⚠️ سه نکته که اگر ندانید همه‌چیز خراب می‌شود

**۱) مدل خط فارسی نمی‌فهمد.**
v2 روی **فونِم لاتین** آموزش دیده. اگر متن فارسی خام بدهید، مدل
**بی‌صدا** بیرون می‌دهد و هیچ خطایی هم نمی‌دهد. برای همین مرحلهٔ G2P
اجباری است و در `generate.py` خودکار انجام می‌شود.

**۲) نمونهٔ صدا حداکثر ۵ ثانیه.**
آموزش روی نمونه‌های ۵ ثانیه سقف خورده. نمونهٔ بلندتر باعث می‌شود مدل
به‌جای متن شما، **ادامهٔ جملهٔ خودتان** را بگوید — با صدای درست ولی
حرف بی‌ربط. آزمون خودشان: ۰ از ۴ با ۶.۱ ثانیه، ۴ از ۴ با همان فایل
بریده‌شده به ۵ ثانیه.

**۳) تکه‌ها باید ~۱۱ فونِم باشند.**
مدل روی جمله‌های ~۴ ثانیه‌ای آموزش دیده. تکهٔ ۲۱ فونِمی و بیشتر
ممکن است هیچ‌وقت تمام نشود و تکرار کند (`fanAvari` → `fanAvariiiiii`).
`generate.py` خودکار روی جمله و بند می‌شکند و تکه‌های کوتاه را به هم
می‌چسباند.

## فایل‌ها

```
ai/
  scripts/generate.py    ← اسکریپت اصلی تولید صدا
  requirements.txt       ← وابستگی‌ها
  voices/                ← نمونهٔ صدای شما (اینجا می‌گذارید)
    README.md
  out/                   ← صداهای تولیدشده
    index.json           ← فهرست (صفحهٔ سایت همین را می‌خواند)
    *.wav
ai.html                  ← صفحهٔ تست در سایت
.github/workflows/ai-tts.yml   ← ورکفلو
```

## اجرای لوکال (اختیاری)

روی سیستم شما هیچ‌چیز لازم نیست، ولی اگر خواستید:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r ai/requirements.txt
python ai/scripts/generate.py --text "سلام، حالت چطور است؟" --voice ai/voices/my_voice.wav
```

## عیب‌یابی

| مشکل | علت | راه‌حل |
|---|---|---|
| صدای خروجی **سکوت** است | متن بدون G2P به مدل رسیده | نباید پیش بیاید — `generate.py` خودکار فونِم می‌کند |
| مدل **حرف بی‌ربط** می‌گوید | نمونهٔ صدا بلندتر از ۵ ثانیه | نمونه را به ۵ ثانیه ببرید |
| کلمه‌ها **تکرار** می‌شوند | تکهٔ فونِمی بلند | `--pause-sec` را زیاد کنید یا متن را کوتاه‌تر |
| `ValidationError: capitalize_first_letter` | نسخهٔ رسمی pocket-tts نصب شده | فورک را نصب کنید (در requirements هست) |
| صدای خروجی **کیفیت پایین** | نمونهٔ صدا نویزی | نمونهٔ تمیزتر بگذارید — مدل نویز را بازتولید می‌کند |
| ورکفلو **زمان‌بر** است | کش خالی | بار دوم سریع می‌شود |
