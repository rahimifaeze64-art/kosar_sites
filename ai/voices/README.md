# نمونهٔ صدا 🎙

فایل صدای خودت را **همین‌جا** بگذار. مدل از این نمونه صدایت را کلون می‌کند.

## قواعد مهم

| مورد | مقدار |
|---|---|
| **مدت** | **حداکثر ۵ ثانیه** ⚠️ |
| فرمت | `wav` یا `mp3` (wav بهتر است) |
| محتوا | یک جملهٔ کامل و روان فارسی |
| کیفیت | بی‌نویز، بدون موسیقی پس‌زمینه |

> ⚠️ **سقف ۵ ثانیه را جدی بگیرید.** مدل روی نمونه‌های ۵ ثانیه‌ای آموزش دیده.
> نمونهٔ ۶ ثانیه‌ای باعث می‌شود مدل به‌جای خواندن متن شما، **ادامهٔ جملهٔ
> خودتان** را بگوید — با صدای درست، ولی حرف بی‌ربط.
> (آزمون خودشان: ۰ از ۴ درست با ۶.۱ ثانیه، ۴ از ۴ با همان فایل بریده‌شده به ۵ ثانیه)

## چطور بگذارم؟

**راه ۱ — از سایت گیت‌هاب (ساده‌ترین):**

۱. برو به: `https://github.com/rahimifaeze64-art/kosar_sites/upload/main/ai/voices`
۲. فایل صدا را بکش و رها کن
۳. اسمش را `my_voice.wav` بگذار
۴. Commit کن

**راه ۲ — با git:**

```bash
git add ai/voices/my_voice.wav
git commit -m "افزودن نمونهٔ صدا"
git push
```

## نام فایل

نام پیش‌فرض `my_voice.wav` است. اگر اسم دیگری گذاشتید، در تب Actions
هنگام اجرای ورکفلو همان اسم را در کادر «نام فایل نمونهٔ صدا» بنویسید.

## چطور ضبط کنم؟

با گوشی، در یک اتاق ساکت. یک جملهٔ کامل بگویید، مثلاً:

> «سلام، من مسئول پیگیری کارهای دانشجویان هستم و آمادهٔ کمک به شما هستم.»

بعد در واتساپ یا هرجا به ۵ ثانیه ببریدش و بفرستید.

## نکتهٔ فنی

کیفیت صدای نمونه **مستقیماً** در کیفیت خروجی اثر می‌گذارد — مدل هر نویز و
اکوی نمونه را هم بازتولید می‌کند. اگر صدای بهتری می‌خواهید، نمونهٔ تمیزتر بگذارید.
